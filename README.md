## 📌 Project Overview

This project performs an end-to-end exploratory analysis of Blinkit grocery sales data using Python.

The objective is to transform raw grocery retail data into meaningful business insights by analyzing **sales performance, product categories, item fat content, outlet characteristics, customer ratings, and outlet establishment trends**.

The analysis includes data exploration, data cleaning, KPI calculation, aggregation, and visualization using Python's data analysis and visualization libraries.

---

## 🎯 Business Objectives

The analysis focuses on answering key business questions:

* What is the overall sales performance?
* Which product categories generate the highest sales?
* How does sales performance vary by item fat content?
* Which outlet locations contribute the most revenue?
* How does outlet size affect sales?
* How have sales changed based on outlet establishment year?
* How do different outlet types perform?
* What is the overall customer rating?
* Are there differences in product preferences across outlet location tiers?

---

## 📊 Dataset

The dataset contains **8,523 records and 12 attributes** related to grocery products and outlet performance.

### Dataset Columns

| Column                      | Description                                 |
| --------------------------- | ------------------------------------------- |
| `Item Fat Content`          | Fat-content classification of the product   |
| `Item Identifier`           | Unique product identifier                   |
| `Item Type`                 | Product category                            |
| `Outlet Establishment Year` | Year the outlet was established             |
| `Outlet Identifier`         | Unique outlet identifier                    |
| `Outlet Location Type`      | Outlet location tier                        |
| `Outlet Size`               | Size classification of the outlet           |
| `Outlet Type`               | Type of retail outlet                       |
| `Item Visibility`           | Visibility of the product within the outlet |
| `Item Weight`               | Product weight                              |
| `Sales`                     | Sales generated by the item                 |
| `Rating`                    | Customer rating                             |

## 🧹 Data Cleaning & Preparation

The analysis includes several data-quality checks and preparation steps.

### Data Quality Checks

* Checked dataset dimensions
* Reviewed column names
* Examined data types
* Investigated duplicate records
* Checked missing values
* Reviewed descriptive statistics
* Examined categorical values

The notebook found **no duplicate rows** in the dataset.

### Standardization

The `Item Fat Content` column contained inconsistent representations such as:

* `Low Fat`
* `low fat`
* `LF`
* `Regular`
* `reg`

These values were standardized into consistent categories:

* `Low Fat`
* `Regular`

This improves the accuracy and consistency of subsequent grouping and visualization.

## 📊 Exploratory Data Analysis

The project uses multiple visualizations to examine different dimensions of sales performance.

### 1. Sales by Item Fat Content

Analyzed total sales generated by **Low Fat** and **Regular** products to understand the contribution of different product types.

### 2. Sales by Item Type

Compared sales across grocery categories to identify the strongest and weakest-performing product categories.

### 3. Item Fat Content by Outlet Location

Analyzed the relationship between product fat content and outlet location tiers to identify differences in product performance across markets.

### 4. Sales by Outlet Establishment Year

Used a time-series visualization to examine how sales vary according to the year in which outlets were established.

### 5. Sales by Outlet Size

Compared sales generated by different outlet sizes to understand the relationship between outlet capacity and revenue.

### 6. Sales by Outlet Location

Analyzed sales across **Tier 1, Tier 2, and Tier 3** outlet locations.

The notebook identifies Tier 3 outlets as the highest-sales location group, with approximately **472,133** in sales.

### 7. Sales by Outlet Type

Compared performance across different outlet types to understand which formats contribute most strongly to sales.

### 8. Outlet-Level Analysis

The project also explores outlet-level sales patterns and combines multiple outlet attributes to provide a broader view of retail performance.
